# Capture list — the inputs that have to be shot by hand

The PDFs and JSON in this folder are generated by
`uv run python scripts/generate_synthetic_data.py`. The rest cannot be
generated convincingly, and the whole point is that the inputs are genuinely
messy — a clean render of a document proves nothing about handling a real one.

Budget: about 25 minutes with a phone. Do it once, early. Every demo scene needs
these, and re-shooting on the last day is how demos slip.

**Nothing here may show real personal data.** Write the labels yourself on blank
paper or print the generated PDFs and photograph those.

## Photos — `photos/`

| File | What to shoot | The point |
|---|---|---|
| `pill-bottle-01.jpg` | A bottle with a handwritten label: `Synthecillin 5 mg — 1 daily with food`. Shoot at an angle, indoor light, your hand's shadow across it | Angle + shadow + handwriting is the realistic case |
| `pill-bottle-02.jpg` | Second label: `Cardiolex 20 mg — morning and night`. Slightly out of focus | Tests extraction under blur |
| `blister-pack.jpg` | A blister pack photographed from above with glare on the foil | Glare defeats naive OCR |
| `appointment-slip.jpg` | Handwritten on paper: `Follow-up — Dr Sandoval — Tues 14:30, bring the lab result`. Crumple it first, then flatten | Handwriting + creases |
| `benefits-letter-scan.jpg` | Print `benefits-letter.pdf`, photograph it crooked with one corner folded | Same content as the clean PDF — good A/B for the extraction step |

## Voice notes — `audio/`

Record on a phone, in a corridor or kitchen, at normal speaking speed. Background
noise is wanted, not a defect.

| File | Roughly say | The point |
|---|---|---|
| `carer-note-01.m4a` | "Um, so the nurse came this morning — she said the Synthecillin goes up to ten milligrams? I think. And we still haven't sent that CC-12 form, the deadline's coming up." | Hesitation, an uncertain fact, and a real action item |
| `carer-note-02.m4a` | Same content but switching between Vietnamese and English mid-sentence | Code-switching is the realistic case for a bilingual household, and it is exactly the "unusual, messy" input the brief asks for |
| `carer-note-03.m4a` | "Sorry, ignore what I said about Tuesday, they moved it to Thursday." | A correction that supersedes an earlier fact — feeds conflict resolution |

## Checking the injection still works

```bash
uv run python -c "
from pypdf import PdfReader
t = PdfReader('fixtures/synthetic/lab-result-tampered.pdf').pages[0].extract_text()
print('injection extractable:', 'Ignore all previous instructions' in t)"
```

Open the same PDF in a viewer and confirm you cannot see it. That contrast is
the demo.
